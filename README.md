# 🏎️ Jinha's F1 Archive

F1 드라이버들에게 바치는 개인 팬 아카이브 프로젝트.
단순히 정보를 나열하는 것을 넘어, 각 드라이버의 개성과 에너지를
웹 인터랙션으로 번역해보고 싶은 실험이다.

> **"Simply, simply lovely!"** — AI(Claude)와 함께한 Vibe Coding 프로젝트

---

## 🔵 Episode 01 — George Russell #63

차분함 속의 속도, 분석적 완벽함 — **"Mr. Saturday"** 조지 러셀을 위한 헌정 페이지.
메르세데스 AMG 페트로나스의 시그니처 컬러를 시각 언어로 삼아,
드라이버의 존재감을 화면에 담았습니다.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Dynamic Loading Screen** | "63" 넘버를 강조한 메탈릭 오프닝 연출 |
| **Hero Typing Effect** | "Mr. Saturday", "2022 Brazil GP Winner" 등 문구 순환 타이핑 |
| **Gallery Lightbox** | 이미지 클릭 → 전체화면 확대, 키보드 (←→ / Esc) 지원 |
| **Race Result Filter** | All / WIN / Podium 버튼으로 경기 결과 필터링 |
| **Live Stats Counter** | 스크롤 진입 시 수치가 카운트업되는 애니메이션 |
| **Career Timeline** | 카팅부터 메르세데스까지의 커리어 하이라이트 |
| **Dark / Light Theme Toggle** | 네비게이션 바 태양/달 아이콘으로 테마 전환 (localStorage 저장) |
| **Mobile Hamburger Menu** | 모바일 대응 접이식 네비게이션 |
| **Social Links** | X(Twitter), Instagram, F1 공식 페이지 연결 |
| **Scroll-aware Navbar** | 현재 섹션에 맞게 활성 링크 자동 하이라이트 |

## 🎨 Design Concept

* **Color Palette**: Dark `#111111` · Metallic Silver `#C0C0C0` · Petronas Teal `#00D2BE`
* **Typography**: Helvetica Neue 계열 — 레이싱 넘버판의 단호함
* **Mood**: 속도보다 정밀함, 화려함보다 우아함 — GR63의 드라이빙 스타일에서

## 🛠 Tech Stack

* **Frontend**: HTML5, CSS3, Vanilla JavaScript (프레임워크 없음)
* **Vibe Tech**: AI(Claude)와의 협업을 통한 자연어 기반 코드 생성

모든 기술 선택은 빠른 실험과 감각 조정을 우선으로 했다.

## 🚀 How to Run

```bash
git clone https://github.com/KimJinha-JJin/sample-directory.git
cd sample-directory
# index.html을 브라우저에서 바로 열면 됩니다
open index.html
```
