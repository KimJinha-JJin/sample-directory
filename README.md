# 🏁 F1 Driver Fan Site — Archive

> **"It's all about speed, passion, and the people who define the sport."**
> AI와 함께한 즐거운 'Vibe Coding' 프로젝트

이 레포지토리는 F1 드라이버들을 위한 개인 팬사이트 실험 공간입니다.
드라이버별로 각기 다른 색깔과 개성을 웹 인터랙션으로 풀어내는 것을 목표로 합니다.

---

## 🚀 Driver Fan Sites

| 드라이버 | 팀 | 스타일 키워드 | 상태 |
|---|---|---|---|
| 🔵🔴 Max Verstappen | Red Bull Racing | 속도, 집중, 압도적 지배 | ✅ 완료 |
| 🟢 George Russell | Mercedes-AMG | 정밀함, 성장, 우아한 레이싱 | ✅ 완료 |
| ➕ 추가 예정 | — | — | 🔜 |

---

## ✨ Key Features (공통)

* **Dynamic Loading Screen**: 드라이버 번호를 강조한 강렬한 오프닝 연출
* **Custom F1 Cursor**: 사이트 전체에서 F1 머신 모양의 전용 커서 사용
* **Live Stats Counter**: 챔피언십 횟수와 승수를 생동감 있게 보여주는 애니메이션
* **Responsive Timeline**: 데뷔부터 현재까지의 커리어 하이라이트 정리
* **Interactive Quote Slider**: 드라이버의 상징적인 명언들을 확인할 수 있는 슬라이더

---

## 🛠 Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
* **Vibe Tech**: AI(Claude)와의 협업을 통한 자연어 기반 코드 생성 (Vibe Coding)

모든 기술 선택은 빠른 실험과 감각 조정을 우선으로 한다.

---

## 🎨 Design Concept

각 드라이버의 팀 컬러와 개성을 그대로 담아,
단순히 정보를 나열하는 것을 넘어 **느끼게 하는 웹**을 목표로 합니다.

---

## 🚀 How to See

1. 이 레포지토리를 클론하거나 파일을 다운로드합니다.
2. 각 드라이버 폴더의 `index.html` 파일을 브라우저에서 실행하면 바로 확인할 수 있습니다!
